### 확인 과정에서 찾아 고친 문제

| 찾은 현상 | 원인 | 조치 |
|---|---|---|
| 앱을 다시 켠 직후 같은 구간이 두 번 기록됨 | 차량 서비스가 직전보다 작은 이전 누적거리 값을 한 번 더 보냄 | 직전보다 작은 값은 버리고, 이미 기록한 구간과 겹치는 구간은 새 운행으로 만들지 않음 |
| 앱 실행 직후 누적거리 전체가 운행 1건으로 기록됨 | 차량 서비스가 이전에 보관한 값(0.0)을 먼저 보내고 곧이어 현재 값을 보냄 | 신호를 받기 시작한 뒤 3초 동안은 값을 표시만 하고 그 뒤의 값부터 기준점으로 사용. 정차 중 한 번에 2,000 km 넘게 늘어난 값은 운행으로 보지 않음 |
| 내보내기 창의 글자와 닫기 버튼이 작게 표시됨 | 대화상자에 화면 배율이 적용되지 않음 | 대화상자 내용에 같은 배율 적용, 닫기 버튼 확대 |
